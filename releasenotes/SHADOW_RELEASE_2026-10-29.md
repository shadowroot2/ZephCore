# Shadow ZephCore 1.18.0 — 2026-10-29

Обновление ShadoW на базе [авторской ZephCore](https://github.com/liquidraver/ZephCore)
с совместимостью протокола [MeshCore](https://github.com/meshcore-dev/MeshCore).
Состав плат повторяет релиз `shadow-v20261014.1`.

## Из основной прошивки

С прошлого опубликованного выпуска 1.17.4 вошли изменения 1.17.5b,
1.17.5c, 1.17.6, 1.17.7 и 1.18.0:

- Настройки перенесены в `prefs.json` с миграцией прежнего формата.
  Уменьшено число записей контактов, настроек и ACL во flash; исправлено
  сохранение данных на внешнем flash и сброс отложенных записей при выключении.
- Компаньон работает по WiFi/TCP на поддерживаемых платах. Исправлены
  зависания USB при старте, закрытии порта и потере хоста, импорт контактов,
  задержки сообщений до переподключения и обработка таблицы услышанных узлов.
- Remote CLI protocol v14 выполняет команды разрешённых контактов.
  Исправлены ограниченные ответы с тегом запроса.
- Уточнены path hashes: общий заводской режим с двухбайтовыми хешами,
  обработка прямых advert и восстановление повреждённых обратных маршрутов.
- Исправлены управление GPS, применение duty interval на репиттерах,
  сохранение данных при standby и тайм-аут холодного старта. Приёмник,
  отсутствующий физически, больше не запускает постоянный поиск.
- Исправлены восстановление времени после reboot, распознавание RTC и
  проверка свежего спутникового фикса перед синхронизацией часов.
- Исправлены RX duty cycle LR1110 и автоматический сброс adaptive CAD
  при изменении радиопресета.
- Доработаны энергосбережение ESP32-S3, остановка WiFi и питание внешнего
  flash у репиттеров. Companion light sleep остаётся выключенным по умолчанию.
- Исправлены подтверждения кнопкой, состояния транспорта на экранах,
  телеметрия питания и батареи. В авторской базе расширена поддержка плат
  и LR2021, включая 2.4 ГГц; добавлена роль KISS modem. Образы новых плат
  и KISS modem в этот набор не входят.
- Из MeshCore 1.18.0: случайная задержка ретрансляции direct ACK, разнос
  повторных ACK при `multi.acks 1`, unscoped floods с transport code 0
  и отказ от устаревшего `set repeat on` у room server.
- Offgrid автоматически выбирает разрешённую offgrid-частоту и возвращает
  прежнюю при выключении; forwarding компаньона ограничен этими частотами.

## Доработки ShadoW

- Полный USB help и категорийный help для BLE и удалённой LoRa CLI.
  Команды показываются с учётом оборудования и роли; ответы ограничены
  размером соответствующего фрейма. Добавлены короткие `tz`, `gps`, `leds`
  и `buzz`, отдельная группа WiFi. Удалён `clkreboot`.
- vContact предназначен для уведомлений; для управления используется
  командная строка. Уведомления приходят при локальном изменении SOS,
  Tracking, GPS, buzzer и LEDs, а также выключении кнопкой.
- Удалённые `sos` и `tracking on|off` работают без звука в течение всего
  сценария, включая промежуточные и финальные отправки.
- Ожидающий GPS ручной SOS отменяется коротким нажатием на T-1000E/M3
  и действием на странице SOS у экранных компаньонов. Отправляется
  `❌ SOS Canceled`, воспроизводится сигнал отмены Fall, восстанавливается GPS.
- Восстановлены страницы и заставка `Tuned by ShadoW`. GPS-страница
  обновляется после фактического переключения; M1/M5 учитывают физический
  переключатель GPS. При выключении показывается `Power OFF`.
- WiFi-страница показывает адрес как `IPv4:port`; переключение WiFi
  сохраняет настройку и перезагружает устройство. Исправлен USB CLI Heltec V3.
- Исправлена зарядная индикация XIAO nRF52840: процентные серии как у
  M3/T-1000E; на внешнем питании heartbeat не показывает ложный низкий заряд.
- Сохранены Fall, SOS с ожиданием свежих координат, Tracking, уведомления
  батареи репиттеров и отдельные конфигурации BLE/ESP-NOW bridge.

## Прошивка и проверка

- UF2 записывается через загрузчик платы. ESP32 merged BIN записывается
  с адреса `0x0`; подписанное приложение находится по `0x10000` у Heltec V3
  и `0x20000` у M5. Не используйте update BIN для первой прошивки.
- Сохранённые радионастройки имеют приоритет над заводским профилем.
  После обновления проверьте частоту и остальные параметры.
- Обычное обновление в той же роли предусматривает сохранение данных.
  Смена companion ↔ repeater очищает данные роли; предварительно сохраните
  identity, контакты и настройки.
- Все 10 образов прошли pristine-сборку; ESP32 собраны с `--sysbuild`.
  Исходники прошивок: [76799fbec](https://github.com/shadowroot2/ZephCore/commit/76799fbec).
  Финальный коммит релиза исправляет упаковщик ESP32 и добавляет результаты
  выпуска; исходники приложения после сборок не менялись.
- Проверены UF2 family, номера блоков, адреса записи и совпадение с результатом
  сборки. Для ESP32 проверены размещение приложения, checksum/hash ESP-образа
  и целостность MCUboot-образа. В Assets находятся только полные merged BIN
  и UF2; update BIN и HEX в этот выпуск не включены.
- Статическая проверка CLI прошла; quick host tests: 128 PASS.
  Аппаратная проверка GPS-страницы OFF → ON подтверждена пользователем;
  успешная компиляция не означает полной проверки новых образов на устройствах.
