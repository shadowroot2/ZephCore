# Shadow ZephCore v20260916.1

Релиз ветки `master`, созданной из рабочей ветки `dev` репозитория
`shadowroot2/ZephCore`. Версия протокола прошивки остаётся `1.16.8-zephcore`.

## Изменения

- Repeater и repeater-bridge: уведомления `Repeater battery low` через LoRa
  в настраиваемую публичную группу, без автоматического выключения.
- Команда `battery`: напряжение, процент заряда, uptime и текущие настройки.
  USB CLI и удалённая консоль; настройки добавлены в help.
- `get/set battery.alert`, `battery.threshold`, `battery.interval`,
  `battery.group`. По умолчанию on, 12 часов, `#zephcore`; порог nRF52 —
  3250 мВ, ESP — 3500 мВ. Порог 0 означает отсутствие уведомлений.
- Три последовательных замера ниже порога с периодом 30 секунд;
  сохранение интервала повторов между перезагрузками. При внешнем питании
  уведомления не отправляются. GPS не включается принудительно: ссылка
  на карту использует последний фикс или заданные координаты репиттера.
- XIAO NRF: независимая зелёная индикация зарядки — 1/2/3 вспышки для
  <50%/50..74%/>=75%, постоянный зелёный от 4190 мВ при USB.
  Красный heartbeat и синий LoRa TX продолжают работать при зарядке.
- BLE bridge: сериализация отправок, очередь 8 кадров с резервом для
  управляющего обмена, защита от устаревших callbacks, контроль таймаутов.
  GATT TX перенесён в system workqueue с неблокирующим выделением ATT-буферов;
  устранён найденный путь бесконечного ожидания в основном цикле.
- Исходники также содержат uptime для companion и индикацию T-ECHO как у M3.
  Нового образа T-ECHO в этом релизе нет.

| `xiao_nrf52840-wio_sx1262-repeater-2026-09-09-battery-status.uf2` | XIAO nRF52840 + Wio-SX1262, repeater | 2026-09-09 | UF2 через загрузчик |
| `thinknode_m6-repeater-bridge-2026-09-11-ble-nonblocking.uf2` | ThinkNode M6, repeater-bridge | 2026-09-11 | UF2 через загрузчик |
| `heltec-v3-repeater-bridge-433-2026-09-11-ble-nonblocking-merged.bin` | Heltec V3 433, repeater-bridge | 2026-09-11 | Полный merged BIN, адрес **0x0** |

Это ранее подготовленные образы, а не новая пересборка всех плат под тегом.
XIAO не содержит BLE bridge. M6 и Heltec содержат исправление неблокирующей
BLE-отправки от 11 сентября. Heltec включает MCUboot и signed app по 0x10000;
записывать весь merged-файл с 0x0. Сохранённые настройки не заменяются
значениями по умолчанию. Старые companion-образы в этот релиз не включены.

## Проверки и ограничения

- Проверены успешные чистые сборки, роли, структура UF2/merged и SHA-256.
- Пользователь подтвердил улучшение стабильности BLE после предыдущих правок.
- Устранение зависания Heltec при входе в LoRa-админку последним исправлением
  пока **не подтверждено на устройстве**. После обновления проверить вход
  в удалённую консоль при подключённом BLE-мосте и длительную работу.
