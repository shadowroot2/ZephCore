## 2. Экраны и меню

### Companion

- Обе заставки — button UI и joystick UI — обязаны показывать логотип ZephCore,
  `MeshCore on Zephyr`, `FIRMWARE_DISPLAY_VERSION`, `FIRMWARE_BUILD_DATE` и
  нижнюю подпись `Tuned by ShadoW`. После обновления автора проверяются оба
  файла: `helpers/ui-button/ui_pages.c` и
  `helpers/ui-joystick/screens/home.cpp`.
- Добавлены страницы Tracking и SOS с действиями соответствующих сценариев.
- GPS-страница обновляет состояние и показывает спутники во время поиска на поддерживаемых платах; Heltec V3 без GPS не должен показывать бесполезную GPS-страницу.
- После GPS off/on callback передаёт экрану фактические enabled и
  `OFF`/`ACQUIRING`/`STANDBY`, затем явно запускает перерисовку. Это общий путь
  для button, joystick и E-Paper UI. Buzzer также обновляет состояние после
  переключения.
- Исправлено поведение Advert: отправка объявления не должна произвольно перемещать пользователя на соседний пункт.
- На всех WiFi companion-сборках ENTER на странице WiFi переключает
  `wifi.enabled`, сохраняет настройку и перезагружает устройство. То же действие
  доступно в joystick UI через `System > Info > WiFi`.
- Адрес подключения показывается одной строкой `IPv4:port`, например
  `192.168.2.2:5000`; отдельной строки `Port 5000` нет.
- Настройки WiFi вынесены в группу `wifi`: BLE и USB CLI выводят её через
  `help wifi`; группа существует только в WiFi companion-сборках.
- Удалённый LoRa CLI компаньена поддерживает категорийный `help` и рабочие
  команды ZephCore для контакта с разрешением remote CLI. Локальными остаются
  identity/WiFi-секреты и SSID, BLE PIN, изменение freq/radio/tx,
  ADC/autoshutdown, offgrid, очистка статистики, выключение, OTA/DFU и erase.
- Heltec V3 автоматически получает companion/CLI по USB-C через CP2102/UART0;
  console и shell не конкурируют с transport за UART callbacks.
- При ручном выключении показывается `Power OFF`; на E-Ink финальный кадр
  сохраняется после отключения. При низком заряде показывается отдельное
  предупреждение о выключении.
- Для M5 доработаны E-Ink, подсветка по кнопке и её тайм-аут, подтверждение Power Off.
- Сохранены авторские страницы и добавлены наши действия поверх них; доступность и навигация зависят от button/joystick-интерфейса и платы.

### Repeater и repeater-bridge

- На главном экране bridge название роли — `REPEATER BRIDGE`.
- Перед uptime добавлена строка `Link:` со статусом `off`, `waiting`, `no peer`, `connected`, `timeout` или `error`.
- Время убрано из отдельной строки главного экрана; используется общее представление времени интерфейса.
- После RADIO размещена страница BRIDGE: включение/выключение, состояние, собственный адрес `MC:` и партнёр `PR:`.
- Для компактного экрана статусы сокращены: `conn`, `wait`, `nopr`, `tout`, `err`, `off`.
- Следующая страница — `BRG INFO`: приоритет, диапазон задержки, `Forwarded` и `Skipped`.
- Добавлен экран Buzzer при наличии оборудования и экран LEDs для bridge.
- Текущий порядок button UI bridge: статус → RADIO → BRIDGE → BRG INFO → BUZZER (если есть) → LEDS → выключение.
- Обычный repeater не получает страницы и транспорт bridge. Его button UI: статус → RADIO → BUZZER (если есть) → выключение.
- Счётчики обновляются при обслуживании состояния UI, не обязательно синхронно с физической пересылкой каждого пакета.

## 3. Светодиодная индикация

### Общие правила зарядных серий

Для M3, T-1000E и XIAO реализована индикация уровня во время внешнего питания:

| Уровень | Индикация |
| --- | --- |
| Менее 50% | Одна вспышка |
| 50–74% | Две вспышки |
| От 75%, но ещё не полный | Три вспышки |
| Полный по порогу платы | Постоянный свет |

- Вспышка — 150 мс, между вспышками — 200 мс, между сериями — 1500 мс.
- Напряжение для зарядной индикации обновляется раз в 30 секунд.
- Полный заряд в этой логике — оценка по напряжению, не измерение зарядного тока и не доказательство завершения химического процесса заряда.
- M3/T-ECHO/T-1000E: зарядная индикация имеет приоритет над обычной активностью. Исправлены случаи, когда её перебивали сообщения, heartbeat или завершение TX.
- T-ECHO: красная индикация низкого заряда мигает тремя короткими импульсами; OFF-фаза гасит отдельный low-battery GPIO, поэтому он не залипает включённым.
- XIAO: зелёная зарядная индикация независима от красного heartbeat и синего TX.
- Провайдеры VBUS и процента батареи устанавливаются до `ui_init()`, потому что
  зарядная работа XIAO запускается внутри инициализации UI.
- Авторские `leds.radio` и `leds.hb` интегрированы с нашей индикацией; их реализация не считается самостоятельным изобретением форка.

### Отличия плат

| Плата | Обычная индикация | Зарядка |
| --- | --- | --- |
| ThinkNode M3 | Зелёный heartbeat; два импульса при непрочитанных; красный — три импульса ниже 20%; синий — LoRa TX | Красные серии; полный — постоянный зелёный |
| T-1000E | Зелёный LED; подтверждения действий и специальные вспышки RX/TX | Зелёные серии; полный — постоянный зелёный |
| T-ECHO | RGB-индикация с исправленными active-low пинами | При USB красный 1 с / 1 с; процент и завершение зарядки по ADC не определяются |
| XIAO nRF repeater | Красный heartbeat; ниже 15% — три импульса; синий LoRa TX | Зелёные серии, затем постоянный зелёный; другие индикаторы не подавляются |
| ThinkNode M1 | Без BLE-соединения heartbeat мигает красным и синим; при подключённом телефоне синий heartbeat выключен (подтверждено пользователем). Предупреждение о разряде сохранено | Не подменяется схемой M3 без отдельной поддержки платы |

У T-1000E отдельно сохранены уведомления при отключённом BLE и подтверждение физического завершения TX. При зарядке они уступают зарядному режиму.

На T-ECHO подтверждено завышение ADC при USB: 4841 мВ и 100% вместо 68% после отключения. Поэтому программный постоянный зелёный и процентные серии убраны; завершение зарядки показывает отдельный аппаратный LED. Это изменение индикации не исправляет завышенные показания телеметрии при USB.

## 4. Кнопки и звук

- У T-1000E и обычного M3 одно нажатие открывает 3-секундное окно активации SOS; удержание не менее 1 секунды в этом окне запускает SOS, иначе отправляется flood advert.
- Если ручной SOS уже ожидает GPS, одно нажатие на T-1000E, M3 или M3-MAMA
  отменяет его и отправляет `❌ SOS Canceled`.
- T-1000E и обычный M3: два нажатия — Tracking, три — buzzer, четыре — LEDs, пять — GPS.
- M3-MAMA наследует всю аппаратную базу и поведение M3. Одно короткое нажатие
  переключает Tracking после штатного окна ожидания, одно короткое с удержанием
  запускает SOS, два коротких отправляют Advert. Звуки Tracking и Advert не
  меняются.
- Эта карта относится к headless T-1000E и M3; прежняя карта M3 с двумя нажатиями для LEDs и пятью для advert больше не актуальна.
- Жесты привязаны к конфигурации платы: раскладка экранного устройства не переносится автоматически на безэкранное.
- Подтверждение переключений светом/звуком согласовано с состоянием настройки.
- `findme` использует мелодию Morse `ZEPHCORE`, примерно C6/1047 Гц на буззере; добавлена в управление компаньеном.
- Fall принудительно звучит при выключенном буззере; SOS и обычные UI-звуки соблюдают mute.
- Подтверждение `Fall canceled...` сопровождается отдельным сигналом.
- Авторские режимы `buzzer off|on|vibrate|sound` сохранены, наши исключения Fall/SOS наложены поверх них.
