# 📱 Как пользоваться сообщениями — коротко

## 👀 Как читать сообщения

1️⃣ Открой экран **PUBLIC** — там все твои чаты и группы.
2️⃣ **Зажми** кнопку — открыть чат.
3️⃣ **Нажми один раз** — листать дальше.
4️⃣ **Нажми два раза** — назад, к списку.

🔔 Новые сообщения — счётчик `(N)` рядом с именем.

## ⚡ Быстрые ответы

Зайди в чат и **зажми** кнопку — вылезут готовые фразы:

> ✅ Да
> ❌ Нет
> 👍 Хорошо
> 📥 Принял
> 🚶 В пути
> 📍 На месте
> 👋 Привет

- 👇 **Одиночное** — вниз по списку
- ☝️ **Двойное** — вверх по списку
- 👌 **Зажал** — отправил!

Строка «Отмена» — просто выйти, ничего не отправляя 🚪

## 🔧 Поменять фразы

Подключи устройство к компу и в терминале:

```
reply set 3 Буду позже
```

Где `3` — номер фразы (от 1 до 7). Всё сохранится само 💾
