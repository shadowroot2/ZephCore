# Сообщения и быстрые ответы

Краткая инструкция для экранного устройства (M1, T-Echo и им подобных).

## Чтение сообщений

Экран **PUBLIC** держит список разговоров: `Public` всегда первым, дальше
открытые каналы, `#каналы`, группы — `[G]Название`, комнаты — `[R]Название`,
личные чаты — просто имя. Внутри блоков — по алфавиту. Рядом с именем —
счётчик новых `(N)`.

- **Удержание** — открыть разговор.
- **Одиночное** — следующая страница сообщений.
- **Двойное** — назад, к списку.

Сообщение читается как шапка и текст: `13:02 Nick` полосой, текст под ней.
Время — `13:02` сегодня, `+1d 13:02` вчера, `18.11 13:02` раньше. Личное
сообщение — одной строкой, его время выделено инверсией, чтобы строки не
слипались.

Своё сообщение носит шапку `13:02 Я`, а справа — исход: `+3` повторили
трое соседей, `+` доставлено (личное), `x` никто не услышал.

## Быстрые ответы

Внутри открытого разговора **удержание** открывает список быстрых ответов —
семь готовых фраз поверх разговора:

> Да · Нет · Хорошо · Принял · В пути · На месте · Привет

- **Одиночное** — шаг вниз по списку.
- **Двойное** — шаг вверх.
- **Удержание** — отправить выбранную фразу; она уходит в разговор и сразу
  появляется в нём с исходом доставки.

Список открывается на «Отмена» — удержание на ней просто закрывает список.

## Настройка фраз

Локально по USB или BLE:

```
reply get 3
reply set 3 Буду позже
```

Слоты `1..7`, до 30 символов, пустой текст очищает слот. Настройки живут в
`prefs.json` и переживают перезагрузку.
